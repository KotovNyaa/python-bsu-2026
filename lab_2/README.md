# Прогнозирование спонтанных преждевременных родов (sPTB) по протеому CVF

Пайплайн обработки мультицентровых масс-спектрометрических данных цервиковагинальной жидкости (DIA LC-MS/MS) и обучения моделей машинного и глубокого обучения для прогнозирования sPTB и стратификации молекулярных подтипов.

## Структура проекта

* **`lab/`** — модуль предобработки данных, реляционного хранения в SQLite (`lab.db`), расчёта весов приборной достоверности переходов MS/MS, гибридной импьютации (`MAR-kNN + MNAR-QRILC`), калибровки `MS -> ELISA` (LUPI) и конструирования биофизических/графовых признаков.
* **`notebooks/`** — эксперименты второго этапа на GPU (Google Colab L4):
  1. `01_CohortA_Tabular_LUPI_and_PriorShift.ipynb` — классические модели, абляция панелей, LUPI и EM-адаптация Саеренса к сдвигу превалентности.
  2. `02_CohortA_TFM_TabPFN_TabICL_TabR_T2G_TabM.ipynb` — табличные foundation-модели (`TabPFN-v2`, `TabICLv2`, `TAG`), графо-табличный трансфер (`G2T-FM`, `InductiveMVGAT`) и глубокие табличные сети (`TabR`, `T2G-Former`, `TabM`).
  3. `03_Chongqing_Proteome_BINN_and_DeepSHAP.ipynb` — онтологические сети (`BINN`, `P-NET`) на полнопротеомной когорте г. Чунцина ($35 \times 2699$) и топологически скорректированный `DeepSHAP`.
  4. `04_MetaEnsemble_CaruanaGES_SaerensEM_and_ClinicalReport.ipynb` — мета-ансамблирование 5 семейств моделей, бутстреп/тест ДеЛонга и клинический разбор ошибок.
* **`plots/`** — итоговые диагностические графики.
* **`tests/`** — тесты пайплайна предобработки.
